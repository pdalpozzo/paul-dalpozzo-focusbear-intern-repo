The idea behind the unlocking tools isn't about the levels or achievements, it's about teaching the user about the features they can use. This gives us some clear rules to follow when setting the goals for the next unlock.
1. There must be more than one goal for each feature
2. The goal must be possible with the feature that is unlocked
3. The goal must be useful for the user to know

Consider the focus sessions. What would the user find useful? What must they know?
- how to start a session
- how to set the timer
- how to enable breaks - not achieveable unless habits have been done
- how to end a session
- how to set an active task - not achieveable unless they have set a task

This gives us 5 possible goals. 2 have conditions that the user might not be aware of yet. 3 are must know and exclusive to the focus session. Are the exclusive goals enough to consider the user knows how to use the focus session? I think so.

But do we want to restrict the user to only those 3 goals? no. Let's give consider that they can complete any 3 of the 5 to understand a focus session. This gives us our first achievement.

Learn Focus Sessions by completing any 3 of these goals
- start a focus session
- change the timer of a focus session
- enable breaks before starting a focus session
- end a focus session
- assign an active task during a focus session

What do you get for completing this achievement? You unlock the next feature. So let's zoom out. What features/tools do we have to offer, which should be unlocked at the start and which order should we give them to the user. Should we allow the user to select the tool they want?

Focus session is a must have. Jeremy would consider blocking to be a must have. Breaks are a must have as well, but we cannot have breaks unless we have habits. This makes Habits a must have. This is too much to start off. The issue here is that habits are a big step in learning, but so much relies on them. We need to offer a break without habits. It should be possible for the user to just have a 2 minute break where the PC is locked and no habits exist to guide them.
