# Issue 1

I was given the **Usability Tester & Bug Hunter** role. 

**I noticed:**
- there was a way for the user to report bugs and request features.
- there are so many features. It would be hard to track and test how they all interact with each other.
- it has a lot of potential. The whole time watching the onboarding playlists I was thinking of how it could be used to help kids with screen time issues or how it could possibly track your life and automatically assume tasks based on your location. It even has potential to help with things like gaming. Say you have set aside 8 hours to play a game that just came out, you could have Focus Bear remind you to take breaks and drink water. It can even suggest exercises to do in those breaks so that your body doesn't feel terrible after sitting for 8 hours.
- it requires a lot of managing. There are things in place to help mitigate the effort put into managing blocks, tasks and etc. but it seems like there is still a lot to do. Maybe this is something that the user develops over times.
- Lifetime subscription is $150? That is so cheap for what this app does.
- the tutorials are great. They have images and very simple steps when showing how to perform a task.
- pomodoro breaks. It means tomato in Italian. Maybe there is some fun way to incorporate tomatoes into the theme. Maybe rewarding tomatoes for achieving the goals of the focus? I see that it comes from the Pomodoro Technique.
- that font size is never available to change.

**Completing this issue, I learnt:**
- Of the Eisenhower Matrix. That is pretty cool.
- About the Focus Button. Amazing idea.
- This product is good value for money if the user uses it. Making it as easy to use as possible is the key to this apps success.
- The strict way of keeping focus using the app is very similar to how the teaches at my sons school try to keep the children's focus on their tasks. It is a school for autistic children.
